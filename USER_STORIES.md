# Peerwheel — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### AV fleet / owner operator

- As an AV owner, I want to list idle hours and see expected net yield, so that sharing is an economic decision rather than a guess.
- As an AV owner, I want peer settlement without multi-day payment float, so that cash flow matches utilisation.
- As a fleet dispatcher, I want to pull a vehicle from the marketplace instantly when a safety recall hits, so that we do not keep earning on unsafe assets.

### Rider

- As a rider, I want on-demand AV availability with taxi-comparable pricing, so that I am not forced into opaque surge without alternatives.
- As a rider, I want a verifiable ride receipt for disputes, so that I am not arguing from screenshots alone.
- As a rider, I want to refuse a vehicle whose integrity attestation failed pre-ride checks, so that “trustworthy ride” is enforceable.

### Settlement and dispute ops

- As a settlement operator, I want IoT integrity holds to block payout until cleared, so that vehicle-security claims are not ornamental.
- As a dispute mediator, I want both parties’ attestations and the append-only ride history in one case file, so that resolution meets the thesis’s legal-traceability goal.

### City partnership / compliance

- As a city partnership manager, I want corridor-level pause and licensing tags on vehicles, so that we can operate inside local transport rules.
- As a compliance officer, I want retention and purpose tags on telemetry used for proofs, so that integrity evidence does not become unbounded surveillance.

### Product / strategy (canvas)

- As a mobility product lead, I want to revise value proposition and customer segment fit together and see channel KPIs move, so that we honour the thesis ranking of VP + channels over static revenue tables.
- As a CFO sponsor, I want monthly cost/revenue variance against the canvas plan, so that underestimated payroll-style cost surprises surface early.
